# LocalEats 🍔

Sistema web tipo Uber Eats simplificado.

##  Tecnologías
- Next.js
- Prisma
- MySQL
- Tailwind CSS

##  Funcionalidades Sprint 1
- Registro de usuarios
- Login de usuarios
- Encriptación de contraseñas
- Conexión a base de datos

##  Equipo
- Dev 1: Backend / Base de datos
- Dev 2: API
- Dev 3: Autenticación
- Dev 4: Frontend

##  Cómo ejecutar
npm install  
npm run dev
